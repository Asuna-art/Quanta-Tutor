# 金融数学核心概念中文速查

## 第1章 数据与金融建模

### 模型(Model)
模型是对真实世界系统的简化表示,帮助我们理解复杂现实并做出决策。在精算和金融中,模型用于定价(pricing)、准备金估算(reserving)和资本建模(capital modelling)。

### 现金流模型(Cashflow Model)
现金流模型描述财务交易中各时间点的资金流入(inflow)和流出(outflow)。每个现金流的金额(amount)和时间(timing)可能是确定的也可能是不确定的。

### 常见金融工具
- **零息债券(Zero-coupon bond)**: 不支付定期利息,到期时按面值偿还
- **固定利率债券(Fixed-interest security)**: 定期支付固定利息
- **指数挂钩债券(Index-linked security)**: 利息和本金随通胀指数调整
- **股票(Equity)**: 代表公司所有权,可能支付股息
- **年金(Annuity certain)**: 在固定期限内定期支付的金额

## 第2章 利率介绍

### 单利(Simple Interest)
本金 C,年利率 i,n 年后的金额: C(1+ni)。利息只基于本金计算,不计入复利。

### 复利(Compound Interest)
本金 C,年利率 i,n 年后的金额: C(1+i)^n。每期的利息加入本金继续计息。

### 名义利率与实际利率
- **实际年利率(Effective annual rate) i**: 一年内实际产生的利息比率
- **名义利率(Nominal rate) i^(p)**: 按 p 次复利的名义年利率,关系为 (1+i^(p)/p)^p = 1+i
- **贴现率(Discount rate) d**: d = i/(1+i),满足 (1-d) = 1/(1+i) = v

### 利率力(Force of Interest)
δ = ln(1+i),连续复利的瞬时利率。一般地,δ(t) 可随时间变化,累积因子为:
A(t1,t2) = exp(∫[t1,t2] δ(s)ds)

### 现值(Present Value)
未来时刻 t 的金额 C 在 t=0 的现值为 C·v^t,其中 v = 1/(1+i) 为贴现因子。

## 第3章 年金与现值方程

### 等额年金现值
n 期等额支付 1 元的年金现值: a_n = (1-v^n)/i
n 期等额支付 1 元的年金累积值: s_n = ((1+i)^n - 1)/i

### 期初年金(Annuity-due)
ä_n = (1-v^n)/d = (1+i)·a_n
s̈_n = ((1+i)^n - 1)/d

### 递延年金(Deferred Annuity)
m|a_n = v^m · a_n,在第 m 期后开始支付的 n 期年金现值。

### 连续年金
ā_n = (1-v^n)/δ,连续支付率为 1 的 n 期年金现值。

### 价值方程(Equation of Value)
比较现金流的关键工具,通常将所有现金流贴现到同一时刻求平衡:
∑ Cₖ · v^(tₖ) = 0

## 第4章 贷款偿还表

### 等额还款贷款(Level Annuity)
贷款 L,以利率 i,等额还款 P 偿还 n 期: L = P·a_n,即 P = L/a_n

### 还款表结构
每期还款分为利息部分(本期未偿余额×i)和本金部分(还款额-利息部分)。
未偿余额随时间递减,利息部分占比逐期下降,本金部分逐期上升。

## 第5章 投资项目评估

### 净现值(Net Present Value, NPV)
NPV(i) = ∑ Cₜ · v^t,所有未来现金流按利率 i 贴现到现在的总和。
NPV>0 项目可接受,NPV<0 项目应拒绝。

### 内部收益率(Internal Rate of Return, IRR)/收益率
使 NPV=0 的利率,即 NPV(IRR)=0。两个项目比较时,IRR 更高未必更优,需结合 NPV 看。

### 回收期(Payback Period)
项目累计现金流首次为正的时刻。简单回收期不考虑货币时间价值,贴现回收期考虑。

### 通胀的影响
名义利率 i 与实际利率 i' 满足: 1+i = (1+i')(1+e),其中 e 为通胀率。
近似地: i ≈ i' + e

## 第6章 固定利率证券

### 债券价格与到期收益率
债券价格是未来现金流(息票+本金)按到期收益率(YTM, y)贴现之和:
P = ∑ Coupon · v^t + F · v^n

### 票面利率与收益率
- 票面利率 g 高于 YTM y → 债券溢价(price > face value)
- 票面利率 g 低于 YTM y → 债券折价(price < face value)
- 平价时 P = F(g = y)

### 资本利得税(Capital Gains Tax)
若买入价低于赎回价,差额视为资本利得,需缴税。计算净收益率时要扣除税款。

### 通胀挂钩债券(Index-Linked Bonds)
本金和息票随通胀指数(如 CPI/RPI)调整,提供实际(real)固定收益。

## 第7章 利率期限结构

### 现货利率(Spot Rate) y_t
从 0 到 t 期的零息债券对应的年化利率: P(0,t) = (1+y_t)^(-t)

### 远期利率(Forward Rate) f_{t,s}
未来从时刻 t 到 s 的利率,无套利条件:
(1+y_s)^s = (1+y_t)^t · (1+f_{t,s})^(s-t)

### 期限结构理论
- **预期理论**: 长期利率反映对未来短期利率的预期平均
- **流动性偏好理论**: 长期投资风险更高,需要流动性溢价
- **市场分割理论**: 不同期限市场相对独立

### 久期(Duration)
**Macaulay 久期**: D = ∑ t·Cₜ·v^t / ∑ Cₜ·v^t,加权平均时间。
**修正久期(Modified Duration)**: D_M = D/(1+y),衡量价格对利率变动的敏感度。
ΔP/P ≈ -D_M · Δy

### 凸度(Convexity)
C = ∑ t(t+1)·Cₜ·v^(t+2) / P,二阶敏感度修正。
ΔP/P ≈ -D_M·Δy + (1/2)·C·(Δy)^2

### 免疫(Immunisation)
Redington 三条件: 资产负债的 PV、Duration 相等且资产 Convexity ≥ 负债 Convexity,可保护组合免受小幅利率变动影响。

## 第8章 理性预期理论(Rational Expectations)

### 基本假设
市场参与者使用所有可得信息形成对未来的无偏预期。预期的随机误差应满足:
- 期望为零
- 与历史信息无关

### 在金融中的意义
- 资产价格反映所有可得信息(有效市场假说)
- 价格变动主要由新信息驱动
- 系统性套利机会不存在
